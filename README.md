# omarchykr-assets

Images used by the Omarchy beginner guides on the Korean community
[cafe.naver.com/omarchykr](https://cafe.naver.com/omarchykr).
The guides link to these files through jsDelivr, pinned to a commit.

네이버 카페 "오마키(Omarchy)" 설치 가이드에 쓰는 그림입니다.
카페 글은 jsDelivr 주소(커밋 고정)로 이 그림을 불러옵니다.

## Contents

| Folder | What | Source |
|---|---|---|
| `img/cards/` | Step guides drawn for the posts (marked "그림 · 실제 화면 아님") | This repository |
| `img/shots/` | Screenshots of the GitHub release pages and the Try Omarchy DMG window | Captured for this repository |
| `img/upstream/win-*.jpg` | Try Omarchy for Windows product images | [omacom/try-omarchy-windows](https://github.com/omacom/try-omarchy-windows) `docs/images`, MIT — see `LICENSES/try-omarchy-windows-MIT.txt` |
| `img/upstream/manual-*.jpg` | Omarchy manual image (converted from WebP) | [omacom/omarchy](https://github.com/omacom/omarchy) `manual/images`, MIT — see `LICENSES/omarchy-MIT.txt` |
